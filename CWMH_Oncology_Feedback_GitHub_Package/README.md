# CWMH Oncology Department Feedback Form

A static HTML sample feedback form for the Cancer Awareness & Patient Care Education Programme at Colonial War Memorial Hospital.

Theme: “Every Story is Unique, Every Journey Matters.”

## Publish using GitHub Pages

1. Sign in to GitHub and create a new repository, for example:
   `cwmh-oncology-feedback`
2. Set the repository to **Public** if you want to use GitHub Pages on the standard free plan.
3. Upload `index.html` and `.nojekyll` from this package to the repository's root folder.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for GitHub Pages to publish the site. The URL will usually look like:
   `https://YOUR-USERNAME.github.io/cwmh-oncology-feedback/`
8. Open the published URL on a phone and test the layout.

## Important: submission is not connected yet

This is a front-end demo. The Submit button displays a notice that responses have not been sent or saved. Before using this form for a real event, connect it to an approved collection method (for example, an organisation-approved Google Apps Script / Google Sheets endpoint), test it, and confirm privacy and access settings.

## QR code

After the live URL works, generate a real QR code pointing to that exact URL. Test the QR code on multiple phones before printing it. Keep the QR code itself unaltered; place decorative cancer-awareness graphics around it rather than editing the QR pattern.
